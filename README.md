# Anish Sandaka — Portfolio

A static website built with HTML, CSS, and a small inline JavaScript snippet.
No package installation or build step is required.

## Open and edit

1. Extract this ZIP.
2. Open the `Anish-Portfolio` folder in Cursor, VS Code, or another IDE.
3. Edit `index.html` for content and links.
4. Edit `style.css` for colors, layout, fonts, and responsive styles.
5. Replace `Anish-Sandaka-Resume.pdf` when your resume changes.

## Preview

Open `index.html` directly in your browser, or run this command from the folder:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000. Refresh the browser after editing.
Press Ctrl+C in the terminal to stop the server.

Fonts load from Google Fonts when connected to the internet; system fonts are used otherwise.

## Publish

These files can be served by any static web host. Upload the folder contents with
index.html at the site's root. Local edits do not automatically update your
existing hosted portfolio.
